## 新增需求

### 需求：默认首屏离线可用

系统必须在不访问第三方字体、favicon 或品牌图标服务的情况下渲染新标签页默认首屏。

#### 场景：网络不可用

- **当** 用户在断网或第三方域名不可达时打开新标签页
- **那么** 搜索引擎图标、界面字体和已打包品牌图标必须立即可见
- **并且** 书签与快捷方式必须显示 Chrome favicon 或本地兜底图标

### 需求：兼容历史图标数据

系统必须迁移旧版 Google S2 和已知 Simple Icons CDN 图标地址，且不得丢失标签的 URL、标题或显式自定义图标。

#### 场景：加载旧版桌面标签

- **当** 已保存标签包含旧版远程图标地址
- **那么** 系统必须将其规范化为自动 favicon 或本地品牌资源并持久化

### 需求：缓存高清网站图标

系统必须优先使用扩展内矢量品牌图标，并将成功取得的 128px Chrome favicon 作为 Blob 持久缓存在 IndexedDB；缓存读取与刷新不得阻塞首屏。

#### 场景：缓存命中

- **当** 用户再次打开新标签页且站点图标已经缓存
- **那么** 快捷方式与书签必须从本地缓存显示图标
- **并且** 断网状态不得产生长时间空白或退回低清远程图标

#### 场景：联网后获得更新图标

- **当** Chrome 在用户访问站点后取得更清晰的 favicon
- **那么** 新标签页必须在后台将该图标刷新进扩展缓存
- **并且** 后续离线打开时必须继续使用缓存版本

### 需求：柔和搜索焦点

系统必须在搜索输入框获得键盘焦点时突出整个搜索栏，禁止在输入区域内部显示高对比度纯白矩形框。

#### 场景：聚焦搜索输入框

- **当** 用户点击搜索框或通过键盘将焦点移入搜索输入框
- **那么** 搜索栏必须显示柔和且可辨识的整体焦点状态
- **并且** 输入框本身不得出现独立的白色矩形描边

### 需求：安全渲染书签数据

系统必须将书签标题和 URL 作为数据写入 DOM，禁止将其作为 HTML 片段解析。

#### 场景：书签包含 HTML 字符

- **当** 书签标题包含标签、引号或事件属性文本
- **那么** 页面必须按纯文本显示内容且不得执行脚本

### 需求：优化背景图片存储

系统必须按当前显示需求缩放上传图片，以不高于 3840px 的最长边和 WebP 0.85 质量保存，并对旧背景执行一次空闲迁移。

#### 场景：上传大尺寸背景

- **当** 用户上传超过显示需求的图片
- **那么** 页面必须先提供即时预览，再在后台保存优化后的版本
- **并且** 后续新标签页必须读取优化版本

### 需求：响应式与可访问交互

系统必须根据视口调整网格列数与分页容量，并为主要控件提供键盘焦点、状态和关闭行为。

#### 场景：窄屏浏览

- **当** 视口宽度跨越 1100px、800px 或 560px 断点
- **那么** 网格必须分别使用 7、5、4 或 3 列并避免水平溢出

#### 场景：键盘操作

- **当** 用户使用 Tab、方向键、Enter、Escape 或 Shift+F10
- **那么** 搜索引擎菜单、快捷方式菜单、侧栏和对话框必须提供可感知且可完成的交互

#### 场景：减少动态效果

- **当** 系统设置 `prefers-reduced-motion: reduce`
- **那么** 非必要动画和过渡必须停用或显著缩短
