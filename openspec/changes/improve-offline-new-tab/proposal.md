# 变更：提升新标签页离线可用性与首屏质量

## 为什么

新标签页的字体、搜索引擎图标、书签图标和品牌图标依赖境外服务，网络受限时会延迟或缺失。现有书签渲染、背景图片处理、响应式布局和键盘交互也存在安全性与可用性缺口。

## 变更内容

- 将默认字体、搜索引擎图标和品牌图标改为扩展内资源。
- 使用 Chrome Manifest V3 favicon API 获取书签和快捷方式图标，将成功取得的高清图标持久缓存，并提供本地矢量图标、字母图标与历史数据迁移。
- 安全渲染书签数据，优化背景图片存储和时钟更新频率。
- 增加响应式分页、键盘操作、柔和焦点管理和减少动态效果支持。

## 影响

- 受影响规范：`new-tab-experience`
- 受影响代码：`manifest.json`、`index.html`、`script.js`、`styles.css`、本地图标资源
- 新增权限：`favicon`，不新增主机权限或第三方运行时依赖；图标缓存复用现有 IndexedDB
