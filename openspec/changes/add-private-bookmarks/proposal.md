# 变更：增加默认折叠的私密书签分类

## 为什么

用户有时需要向他人展示收藏夹，但不希望部分书签标题、图标和地址出现在普通目录、最近添加或搜索结果中。现有侧栏只能完整展示 Chrome 书签树，缺少可恢复的私密分类。

## 变更内容

- 在 Chrome“其他书签”下创建并复用真实的“稍后整理”文件夹，扩展保存其文件夹 ID，并迁移旧“私密收藏”显示名称。
- 收藏夹侧栏底部增加与普通文件夹一致的“稍后整理”分类，默认折叠且不创建内部书签 DOM；每次关闭侧栏后恢复隐藏状态。
- 普通书签可通过右键或 `Shift+F10` 移入“稍后整理”；其中书签可用相同方式移回原目录。
- 移入前记录原父文件夹和索引；原目录不存在时安全回退到“其他书签”。
- 从普通书签树、“最近添加”和搜索结果中排除私密文件夹及其后代，避免折叠状态下泄露标题、图标或 URL。
- 对文件夹被手动删除、书签被外部移动和 Chrome API 失败提供非破坏性恢复与行内提示。

## 影响

- 受影响规范：`private-bookmarks`
- 受影响代码：`index.html`、`script.js`、`styles.css`
- 数据变化：新增 `privateBookmarksFolderId` 和 `privateBookmarkOrigins` 到 `chrome.storage.local`
- 权限变化：无，复用现有 `bookmarks` 与 `storage` 权限
