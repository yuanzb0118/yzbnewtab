## 新增需求

### 需求：真实私密书签文件夹

系统必须在用户首次移动私密书签时，于 Chrome“其他书签”下创建或复用“稍后整理”文件夹，并保存可验证的文件夹 ID；系统禁止在仅打开侧栏时创建或移动书签。已有已保存的“私密收藏”文件夹必须沿用原 ID 并迁移为新名称。

#### 场景：首次移入稍后整理

- **当** 用户对普通网页书签执行“移入稍后整理”
- **那么** 系统必须按需创建真实私密文件夹并将该书签移动进去
- **并且** 原书签标题、URL 和 Chrome 书签 ID 必须保持不变

#### 场景：重复使用现有私密文件夹

- **当** 已保存的私密文件夹 ID 仍指向有效文件夹
- **那么** 系统必须复用该文件夹且不得创建重复文件夹

### 需求：默认隐藏私密内容

系统必须将私密分类以“稍后整理”的普通文件夹样式显示在收藏夹侧栏底部并默认折叠；折叠时禁止将私密后代的标题、URL 或图标写入页面 DOM。

#### 场景：打开收藏夹侧栏

- **当** 用户打开侧栏但未明确展开私密分类
- **那么** 页面必须只在列表底部显示普通文件夹样式的“稍后整理”，不得显示锁、隐藏状态或数量
- **并且** 私密书签不得出现在普通目录、最近添加、搜索结果或可聚焦元素中

#### 场景：临时展开私密分类

- **当** 用户明确展开私密分类
- **那么** 系统必须按需读取并显示其中内容
- **并且** 关闭侧栏或按 Escape 后必须清空私密内容并恢复折叠

### 需求：可恢复移动

系统必须在移入前记录书签原父文件夹与索引，并允许用户将私密书签移回原位置。

#### 场景：移出稍后整理

- **当** 用户对其中书签执行“移出稍后整理”且原父文件夹仍有效
- **那么** 系统必须尽可能按原索引还原书签并清理位置记录

#### 场景：原父文件夹失效

- **当** 用户移出私密书签但原父文件夹已被删除或不可用
- **那么** 系统必须将书签移动到“其他书签”并给出非阻塞提示
- **并且** 禁止删除或复制该书签

### 需求：可访问的私密操作

系统必须为普通和私密书签提供右键与键盘可达的移动操作，并在成功或失败后返回合理焦点及状态反馈。

#### 场景：键盘移动书签

- **当** 用户聚焦书签并按 `Shift+F10` 或菜单键
- **那么** 系统必须打开包含对应移动操作的菜单
- **并且** Escape 必须关闭菜单并将焦点返回触发书签

#### 场景：Chrome API 操作失败

- **当** 创建文件夹、移动书签或读取目录失败
- **那么** 系统必须保留书签当前位置并显示可理解的非阻塞错误
