## 上下文

扩展当前直接渲染 Chrome 书签树、最近添加和搜索结果。用户确认需要“默认折叠的私密分类”，不使用 PIN。为避免只在扩展内分类而仍暴露在 Chrome 书签栏中，本变更使用真实 Chrome 书签文件夹。

## 目标 / 非目标

- 目标：让指定书签离开普通目录；默认不渲染私密内容；支持可恢复移动；不增加权限。
- 非目标：加密书签、抵御主动打开 Chrome 书签管理器的人、同步 PIN、彻底隐藏“稍后整理”文件夹本身或移动整个文件夹树。

## 决策

- 私密文件夹创建在 Chrome“其他书签”根目录下，对外使用低辨识度名称“稍后整理”。优先使用已保存且仍有效的文件夹 ID；ID 丢失时可复用该根目录下唯一的现用名或旧名文件夹，否则按需新建。已保存的旧“私密收藏”文件夹只迁移名称，不改变 ID 或内容。
- 私密入口始终位于扩展侧栏列表底部，并复用普通文件夹视觉。折叠时只显示“稍后整理”，不显示锁、隐藏状态或数量，也不创建子书签 DOM。
- 私密内容只在用户明确展开后读取和渲染；关闭侧栏、重新打开新标签页或按 Escape 后立即清空内容并恢复折叠。
- 普通书签与私密书签使用单独的轻量右键菜单。桌面快捷方式原有右键菜单保持不变。
- 移入前在 `privateBookmarkOrigins[bookmarkId]` 保存 `{ parentId, index }`。移出时优先还原；原父目录不存在或不可写时移动到“其他书签”并清理记录。
- 加载普通树、最近添加和搜索结果前获取私密文件夹后代 ID 集合，并统一过滤。私密文件夹不存在时集合为空，不主动创建文件夹。

## 风险 / 权衡

- 默认折叠只能防止展示时的无意暴露，不是安全边界。界面会用“默认隐藏”而非“加密”措辞，避免虚假安全承诺。
- 移动真实 Chrome 书签会影响浏览器其他书签界面，但符合用户希望从普通书签栏移走的目标；原位置元数据用于可逆恢复。
- Chrome 根目录在不同 Chromium 版本或语言下标题不同，定位时优先使用稳定根节点 ID，并提供树结构回退与错误提示。
- 搜索和最近添加需要额外过滤，但私密后代集合只在侧栏加载时读取一次，并在移动后刷新。

## 迁移计划

首次使用前不创建任何文件夹。用户第一次执行“移入稍后整理”时创建文件夹并保存 ID；已有旧文件夹只改名，书签和快捷方式数据保持不变。删除扩展不会删除或移动 Chrome 中的“稍后整理”文件夹。
