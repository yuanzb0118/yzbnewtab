# 变更：新增历史搜索下拉

## 为什么

用户经常重复搜索相同内容，但当前新标签页不会保留最近搜索词，重复输入效率较低。历史记录需要在本地可用、可删除，并保持现有搜索界面的安静与轻量。

## 变更内容

- 在主搜索框下方增加本地历史搜索下拉，聚焦时显示最近记录，输入时过滤匹配记录。
- 所有搜索引擎共用记录，点击历史词条后使用当前引擎立即搜索。
- 支持删除单条和清空全部，最多保存 20 条、显示 8 条。
- 增加键盘操作、焦点管理和无障碍状态；历史层与搜索引擎菜单互斥。
- 仅使用现有 `storage` 权限，不引入外部依赖或网络请求。

## 影响

- 受影响规范：新增 `search-history`
- 受影响代码：主搜索区 HTML、搜索逻辑和搜索下拉样式
