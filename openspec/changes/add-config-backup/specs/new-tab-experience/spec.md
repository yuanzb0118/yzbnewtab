## 新增需求

### 需求：配置备份与恢复

用户必须能够将新标签页的全部个性化配置导出为一个备份文件，并在其他设备上导入该文件以还原相同的布局与外观。

#### 场景：导出配置

- **当** 用户在设置弹窗中点击"导出配置"
- **那么** 系统生成包含桌面标签、时钟设置、搜索历史、私密书签来源及自定义背景图的 JSON 备份文件并触发下载

#### 场景：导入配置

- **当** 用户选择有效的备份文件并确认导入
- **那么** 系统覆盖本地配置与背景图并刷新页面，使布局与备份内容一致

#### 场景：导入无效文件

- **当** 用户选择的文件不是本扩展生成的有效备份
- **那么** 系统提示错误且不修改任何现有数据
